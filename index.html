安全說明：本系統資料庫託管於 GitHub 雲端，Google 帳號金鑰無法控制 GitHub 服務，因此請勿輸入 Google 金鑰。金鑰僅安全儲存在您本機瀏覽器中，不用擔心外洩。

A 一般同仁（最簡單：使用管理員提供的共用金鑰）

如果您是一般業務同仁，不需要註冊 GitHub 帳號。請直接向系統管理員（如：漢君）索取已經產生的「共用更新金鑰」，複製並直接貼在最下方的輸入框即可！

B 管理員/擁有者（自行註冊並申請全新金鑰）

如果您是系統管理員，或希望使用自己的帳號申請全新金鑰，請依循以下步驟：

  1. 註冊 GitHub 帳號：若無帳號，請至 GitHub 註冊頁面 (點此註冊) 建立免費帳號並完成信箱驗證。
  2. 進入金鑰頁面：點選開啟 GitHub Token 設定網頁 (點此開啟)。
  3. 選擇經典版：點擊畫面中的 產生新令牌 (Generate new token) ▾ 按鈕，並選取「經典版 (classic)」選項。
  4. 填寫設定參數：
    • Note (名稱)：輸入 ricoh-sync
    • Expiration (期限)：下拉選單改選為 No expiration (永不過期)
    • Scopes (權限)：勾選最上方的 [✓] repo 以及列表下方的 [✓] workflow 複選框。
  5. 產生並複製：拉到最下方點擊綠色按鈕，將產生一串以 ghp_ 開頭的金鑰，複製並貼在下方即可。
